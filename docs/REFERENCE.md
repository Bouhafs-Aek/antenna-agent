# Reference paper

The antenna rebuilt and validated in this repository is the work of **Mohamed M. Gad and Mai O. Sallam**. This project
reproduces it for software validation; the antenna design is theirs. Please cite the paper if you use these examples.

**APA**
Gad, M. M., & Sallam, M. O. (2024). High gain antipodal meander line antenna for point-to-point WLAN/WiMAX applications. *Scientific Reports, 14*, 5769. https://doi.org/10.1038/s41598-024-54994-x
